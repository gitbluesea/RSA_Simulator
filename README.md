# RSA 암호화/복호화 교육용 도구 세트 (RSA Crypto Toolsets)

이 프로젝트는 현대 비대칭 키 암호 메커니즘의 근간이 되는 **RSA 알고리즘**의 작동 원리를 쉽게 이해할 수 있도록 제작된 파이썬 스크립트 모음집입니다. 

1973년 클리퍼드 콕스(Clifford Cocks)가 최초 고안하고 1977년 RSA 연구진이 발표한 이론적 배경을 바탕으로, 단순 정수 연산부터 실제 텍스트 데이터의 암호화 처리까지 단계별로 실험해볼 수 있습니다.

---

## 📂 포함된 프로그램 구성

본 프로젝트는 목적에 따라 실행할 수 있는 두 개의 독립적인 스크립트로 구성되어 있습니다.

1. **`rsa_math_simulator.py` (단순 숫자 예시 시뮬레이터)**
   * 교과서나 대화 예시에 나오는 작은 크기의 소수를 활용해 연산 단계를 눈으로 추적합니다.
   * 하나의 정수(M)가 모듈러 거듭제곱을 거쳐 어떻게 암호화되고 복원되는지 수식 위주로 시각화합니다.
2. **`rsa_text_crypto.py` (영어 문자열 암호화 프로그램)**
   * 실제 알파벳 문자열(공백, 특수문자 포함)을 입력받아 암호화합니다.
   * 각 문자를 아스키(ASCII) 코드로 치환한 뒤 배열 형태로 암호화 및 복호화를 수행합니다.

---

## ✨ 주요 기능 및 특징

* **수학적 입력 검증:** 사용자가 입력한 두 수가 올바른 소수(Prime)인지, 서로 다른지 엄격하게 판별합니다.
* **공개 지수(e) 추천 시스템:** 오일러 피 함수 φ(n)과 서로소 관계를 만족하는 올바른 e의 후보군을 자동 연산하여 제안합니다.
* **안전한 모듈러 연산:** 거듭제곱 시 컴퓨터 메모리 오버플로우를 방지하기 위해 파이썬 내장 `pow(base, exp, mod)` 공식을 채택하여 고속 연산을 지원합니다.

## 🚀 실행 및 사용 방법

### 1. 환경 요구사항
* Python 3.8 버전 이상 환경이 필요합니다. (별도의 외부 라이브러리 설치는 필요하지 않습니다.)

### 2. 프로그램 1: 숫자 예시 시뮬레이터 실행
```bash
python rsa_math_simulator.py
```
* **테스트 추천 세팅:** p = 3, q = 11, e = 3, M = 5 
* 입력 시 교과서 공식과 완전히 동일한 단계별 출력을 확인하실 수 있습니다.

### 3. 프로그램 2: 영어 문자열 암호화 프로그램 실행
```bash
python rsa_text_crypto.py
```
* **테스트 추천 세팅:** p = 61, q = 53, e = 17 (텍스트 연산을 위해 약간 더 큰 소수 추천)
* 문자열 `Hello RSA`를 입력하면 내부적으로 숫자가 담긴 배열 데이터로 변환되어 안전하게 암호화됩니다.

---

### 3. 입출력 예시  (숫자 암호화)
```text
=== RSA 암호화/복호화 시뮬레이터 ===
첫 번째 소수 (p)를 입력하세요 (예: 3): 3
두 번째 소수 (q)를 입력하세요 (예: 11): 11

* 추천하는 e 값 목록: [3, 7, 9, 13, 17]
사용할 공개 지수 (e)를 선택하세요: 3

암호화할 메시지 정수 (M)을 입력하세요 (M < 33): 5

========================================
   [ RSA 연산 및 결과 시각화 ]
========================================
* 조건: p = 3, q = 11로 가정
* 계산:
    - n = 3 × 11 = 33
    - φ(n) = (3-1) × (11-1) = 20
    - e = 3 선택 (φ(n)=20과 서로소)
    - 3 × d ≡ 1 (mod 20)을 만족하는 d = 7 결정 (3 × 7 = 21 ≡ 1)
    - 공개 키: (3, 33) / 개인 키: (7, 33)
* 암호화: 보낼 메시지 M = 5 일 때
    - C = 5^3 (mod 33) = 125 (mod 33) = **26**
* 복호화: 암호문 C = 26를 받았을 때
    - M = 26^7 (mod 33) = 8031810176 (mod 33) = **5** (원래 메시지 복원)
========================================
```


## ⚠️ 제약 사항 및 개발자 안내

* **교육 목적 전용:** 본 도구는 알고리즘 원리 이해 및 작동 메커니즘 시각화를 목적으로 설계되었습니다. 눈으로 검증 가능한 작은 소수를 처리하는 데 최적화되어 있습니다.
* **실무 보안 적용 불가:** 실제 상용 서비스(웹 표준, 금융 등)에 적용하려면 최소 **2048비트 이상의 무작위 거대 소수 생성 아키텍처**와 난수 패딩 메커니즘(OAEP 등)이 필수적입니다. 실무에는 본 스크립트 대신 `PyCryptodome` 또는 Python 내장 `cryptography` 라이브러리를 사용하십시오.
