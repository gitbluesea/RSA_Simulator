# RSA 암호화/복호화 시뮬레이터 (RSA Simulator)

이 프로그램은 현대 비대칭 키 암호 메커니즘의 근간이 되는 **RSA 알고리즘**의 키 생성, 암호화, 복호화 전 과정을 수학적 단계에 맞춰 순차적으로 보여주는 CLI 기반 시뮬레이터입니다. 1973년 클리퍼드 콕스(Clifford Cocks)가 고안하고 1977년 RSA 연구진이 발표한 이론적 예시를 직접 수치로 검증할 수 있습니다.

## 주요 기능
* **입력값 예외 검증:** 입력된 두 정수가 올바른 소수(Prime Number)인지, 서로 다른 수인지 자동 판별합니다.
* **공개 지수 (e) 추천:** 오일러 피 함수 φ(n)과 서로소인 올바른 e의 후보군을 계산하여 사용자에게 추천합니다.
* **모듈러 역수 (d) 계산:** 확장 유클리드 호제법 기반 인터페이스를 활용하여 개인 키 지수 d를 자동으로 찾아냅니다.
* **안전한 모듈러 연산:** 거듭제곱 연산 시 오버플로우를 방지하기 위해 파이썬 내장 `pow(base, exp, mod)` 아키텍처를 적용했습니다.

## 실행 방법

### 1. 사전 요구사항
* Python 3.8 버전 이상이 필요합니다.

### 2. 스크립트 실행
터미널 또는 커맨드 라인 창에서 아래 명령어를 입력하여 프로그램을 실행합니다.
```bash
python rsa_simulator.py
```

### 3. 입출력 예시 시나리오
```text
=== RSA 암호화/복호화 시뮬레이터 ===
첫 번째 소수 (p)를 입력하세요 (예: 3): 3
두 번째 소수 (q)를 입력하세요 (예: 11): 11

* 추천하는 e 값 목록: [3, 7, 9, 13, 17]
사용할 공개 지수 (e)를 선택하세요: 3

암호화할 메시지 정수 (M)을 입력하세요 (M < 33): 5

========================================
   [ RSA 연산 및 결과 시각화 ]
========================================
* 조건: p = 3, q = 11로 가정
* 계산:
    - n = 3 × 11 = 33
    - φ(n) = (3-1) × (11-1) = 20
    - e = 3 선택 (φ(n)=20과 서로소)
    - 3 × d ≡ 1 (mod 20)을 만족하는 d = 7 결정 (3 × 7 = 21 ≡ 1)
    - 공개 키: (3, 33) / 개인 키: (7, 33)
* 암호화: 보낼 메시지 M = 5 일 때
    - C = 5^3 (mod 33) = 125 (mod 33) = **26**
* 복호화: 암호문 C = 26를 받았을 때
    - M = 26^7 (mod 33) = 8031810176 (mod 33) = **5** (원래 메시지 복원)
========================================
```
